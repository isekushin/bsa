Ex.05 — Экранные формы (wireframe)

Вид экрана на устройстве пользователя

Экранные формы для роли «Клиент»

barbershop.ru/запись
Главная онлайн-записи MAIN_ONLINE_SIGNUP
Фрейм главной операции
Навигация: Услуги · Мастера · Записаться
Другие операции
Просмотр услуг и мастеров
Фрейм данных (список)
Блоки: Услуги, Мастера (кратко)
Вызовы
Переход к записи → Далее · Отмена — выход
Роль: Клиент (публичный доступ)
MAIN_ONLINE_SIGNUP
barbershop.ru/запись
Выбор мастера SELECT_MASTER
Фрейм главной операции
Выбор мастера из списка
Обеспечивающие операции
Фильтр по услуге; поиск
Фрейм списка / карточка
Список: фото, имя, рейтинг, специализация. Карточка: детали мастера, свободные слоты
Вызовы
Выбрать мастера → Далее · Назад · Отмена
Роль: Клиент
SELECT_MASTER
barbershop.ru/запись
Выбор услуги SELECT_SERVICE
Фрейм главной операции
Выбор услуги из перечня
Обеспечивающие операции
Фильтр по мастеру (если выбран)
Фрейм данных
Список: название, длительность, стоимость; карточка: описание
Вызовы
Выбрать услугу → Далее · Назад · Отмена
Роль: Клиент
SELECT_SERVICE
barbershop.ru/запись
Выбор даты и времени SELECT_DATE_TIME
Фрейм главной операции
Выбор слота (дата + время)
Фрейм данных
Сетка/календарь свободных слотов по выбранному мастеру/услуге
Вызовы
Выбрать слот → Далее · Назад · Отмена
Роль: Клиент
SELECT_DATE_TIME
barbershop.ru/запись
Ввод данных клиента CLIENT_DATA
Фрейм главной операции
Ввод и подтверждение контактных данных
Фрейм карточки данных
Поля: ФИО, телефон, email, канал связи (Telegram/WhatsApp/VK/СМС)
Вызовы
Подтвердить → Забронировать · Назад · Отмена
Роль: Клиент (ввод личных данных)
CLIENT_DATA
barbershop.ru/запись
Подтверждение записи APPOINTMENT_CONFIRMED
Фрейм главной операции
Отображение успешного создания записи
Фрейм карточки
Детали: мастер, услуга, дата, время, контакты
Другие операции
Просмотр детали, отмена записи
Вызовы
На главную · Мои записи · Отменить запись
Роль: Клиент (управление своей записью)
APPOINTMENT_CONFIRMED

Экранные формы для роли «Менеджер»

barbershop.ru/менеджер
Список клиентов MNGR_CLIENT_LIST
Фрейм главной операции
Просмотр и управление базой клиентов
Обеспечивающие операции
Сортировка, фильтрация, поиск; новая запись для клиента
Фрейм списка / карточка
Список: имя, телефон, история записей. Карточка: детали клиента
Вызовы
Добавить · Редактировать · Регистрация клиента · Отмена
Роль: Менеджер (полный доступ)
MNGR_CLIENT_LIST
barbershop.ru/менеджер
Регистрация клиента MNGR_CLIENT_REG
Фрейм главной операции
Ввод и регистрация нового клиента
Фрейм карточки
Телефон, имя; проверка уникальности телефона; генерация временного пароля, СМС
Вызовы
Зарегистрировать → Далее · Отмена
Роль: Менеджер (чтение/запись)
MNGR_CLIENT_REG
barbershop.ru/менеджер
Расписание мастеров MNGR_SCHED_EDIT
Фрейм главной операции
Управление расписанием работы мастеров
Другие операции
Изменение, удаление слотов; фильтр по дате/мастеру
Фрейм данных
Список слотов: дата, время, мастер, статус. Карточка: детали записи
Вызовы
Добавить слот · Редактировать слот · Удалить · Отмена
Роль: Менеджер (полный доступ)
MNGR_SCHED_EDIT
barbershop.ru/менеджер
Добавление слота MNGR_ADD_SLOT
Фрейм главной операции
Создание нового слота для записи
Фрейм карточки
Выбор даты, слот (время 1 ч), мастер из справочника; проверка, что слот не занят
Вызовы
Закрепить слот → Сохранить · Отмена
Роль: Менеджер
MNGR_ADD_SLOT
barbershop.ru/менеджер
Перенос записи MNGR_EDIT_SLOT
Фрейм главной операции
Изменение времени или мастера для уже зарегистрированного слота
Фрейм карточки
Данные записи, контакты клиента; новое время/мастер; отправка СМС об изменении
Вызовы
Сохранить изменения → Уведомить клиента · Отмена
Роль: Менеджер (полный доступ)
MNGR_EDIT_SLOT
